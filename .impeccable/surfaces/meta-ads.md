# Meta Ads workspace

User requested planning and implementing Meta-like paid advertising for Facebook, Instagram and WhatsApp, separate from outbound message campaigns. Preserve CreativeConnects teal MUI shell and Material icons. Operate mode: business managers need clear delivery status, spend, budget, audience and next action.

Plan: company-scoped encrypted ad-account connections and verification; saved campaign/ad-set/ad drafts; adult country targeting and Facebook/Instagram feed placements; single-image website traffic and click-to-WhatsApp creative; paused publication with no blind retry after ambiguous responses; explicit activation/budget confirmation, pause/archive, duplication and local draft deletion; real Meta hierarchy and last-seven-day reports with currency/freshness; tenant/permission/provider tests and rendered UI review.

Real publishing requires Meta API permissions, ad-account billing/access, Page advertising access and linked Instagram/WhatsApp identities. No live ad is published or activated during implementation. This first release is not full Ads Manager parity: video/carousel/catalog creatives, Pixel/CAPI conversions, lead forms, custom/lookalike audiences, experiments, automatic optimization, billing changes and WhatsApp Status placements need separate implementation.

The first release uses manual encrypted token connections and verifies account advertiser tasks, currency and Page-linked identities. Admin and manager roles have ads.view/ads.manage permissions. Ad-set budgets use minor units in the verified account currency; supported currencies are INR, USD, EUR, GBP, AED, CAD, AUD and SGD. Account verification does not certify Meta App Review approval. Existing message campaigns are unchanged.

Partial or ambiguous publication is marked Needs review with any saved provider IDs retained. Complete the review in Ads Manager; no automatic creation retry occurs. Activation and budget changes require explicit UI confirmation and backend acknowledgement. Activation of campaigns created here enables the saved ad and ad set before enabling the parent campaign. Imported campaigns keep their existing child statuses. Ad and ad-set controls verify membership through Meta before mutation. Reports cover Meta's last_7d period, with no simulated metrics. Provider failures retain the previous snapshot. Browser review uses local mock data and does not publish ads or change paid delivery.

Verification: 15 backend tests (62 assertions), all 63 frontend regression tests, typecheck, Pint and production build passed. Local browser fixtures exercised 11 screens/dialogs at 390, 1440 and 1728 with no page errors or document overflow, including draft saves in minor currency units, no automatic publishing, activation cancellation and error recovery. First rendered Better Design spacing review returned zero critical/serious findings on all 11 panels. Copy fixes passed comprehension review. Final spacing rechecks passed on the connection, campaign-goal and creative forms; the service's monthly call cap blocked repeat checks on audience and review forms, whose earlier measurements passed and final screenshots were inspected manually. Evidence is in ignored .impeccable/review/ads-* and meta-ads-browser.mjs. No real advertiser token or paid campaign was exercised.
